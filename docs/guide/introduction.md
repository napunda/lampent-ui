# O que é Lampent UI?

Lampent UI é uma biblioteca de componentes para **Vue 3** construída com **Tailwind CSS 4** e **TypeScript**. Ela oferece componentes acessíveis, customizáveis e prontos para produção, com uma identidade visual inspirada na paleta Lampent.

## Por que usar?

- **Tipagem forte** — props e eventos documentados com TypeScript
- **Tema em runtime** — altere cores e fontes sem recompilar
- **Variantes semânticas** — `primary`, `success`, `warning`, `danger`, `neutral`
- **Leve** — apenas `vue` como peer dependency; estilos pré-compilados
